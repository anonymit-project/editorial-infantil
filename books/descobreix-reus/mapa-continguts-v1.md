# Mapa editorial v1 — Descobreix Reus!

**Fecha:** 20-11-2026  
**Edad:** 5–8 años  
**Estado:** propuesta completa de Fase 3; pendiente de validación editorial final, revisión lingüística y prueba con usuarios. El plan inicial v1 queda desarrollado en este mapa.  
**Experiencia:** explorar, investigar y jugar. No es un libro de colorear ni un cuaderno escolar de fichas repetitivas.

## 1. Posicionamiento y progresión

El niño actúa como pequeño explorador: mira, busca, compara, se orienta, relaciona pistas y reconstruye pequeñas historias de la ciudad. Las actividades alternan respuesta individual, conversación compartida y pequeñas acciones de dibujo.

**Progresión:**
- Actividades 1–4: observación visual y asociación directa (5–6 años).
- Actividades 5–8: secuencias, clasificación y orientación sencilla (5–7 años).
- Actividades 9–12: lectura breve, deducción y cultura festiva (6–8 años).
- Actividades 13–16: mapas, cronología y retos de síntesis (7–8 años, con apoyo adulto disponible).

Cada actividad incluye una consigna breve en catalán. Las actividades con lectura ofrecen apoyo iconográfico y pueden resolverse en voz alta con un adulto.

## 3. Reglas para mapas, datos y soluciones

- No reutilizar mapas turísticos, cartografía comercial, placas de la Ruta ni ilustraciones institucionales. Crear un mapa esquemático original a partir de datos espaciales verificados.
- No dibujar una ruta con orden o distancias si no se han contrastado todos los puntos. El mapa D13 queda condicionado a comprobar trazado y ubicaciones exactas antes del arte.
- La actividad D14 requiere una base cartográfica municipal o coordenadas comprobadas; no se acepta una colocación aproximada de memoria.
- Los años y fechas se presentan como datos acompañados por una fuente; no se evalúa memorización.
- Las respuestas abiertas (D16) llevan criterios de corrección para adultos, no una solución cerrada.
- Las actividades de cultura festiva usan nombres y categorías documentadas; no reproducen diseños locales reconocibles ni atribuyen a una figura genérica el aspecto de una pieza de Reus.

## 4. Diferenciación frente a los libros de colorear

- No se reutilizan ilustraciones de Petits o Grans.
- Casa Navàs puede aparecer como detalle de observación o asociación, no como lámina para colorear.
- El Seguici se aborda como sistema cultural, categorías, vocabulario e historia, no como una serie de retratos.
- La acción principal siempre es buscar, unir, ordenar, clasificar, seguir un mapa, leer una pista o dibujar una respuesta.
- El color es una ayuda de navegación, nunca el único código de respuesta.

## 5. Soluciones y diseño de página

Cada actividad ocupará una página o doble página según el espacio requerido. Los mapas y las escenas de búsqueda deben tener el espacio visual dominante; las respuestas no pueden quedar comprimidas en una franja inferior.

Espacios mínimos de trabajo:
- Búsqueda: imagen principal que ocupe al menos 55% del área útil.
- Asociación: líneas de unión con separación suficiente para evitar cruces confusos.
- Clasificación: grupos con áreas amplias y casillas grandes.
- Secuencia: 3–4 tarjetas con numeración o espacio para escribir.
- Mapa: leyenda visible, recorrido con línea gruesa y espacio para marcar.
- Dibujo: recuadro de al menos un tercio de página.

## 7. Criterios de aceptación

- 16 actividades, progresión gradual y al menos seis familias de juego.
- Cada consigna está en catalán natural y expresa una sola acción principal.
- Cada actividad tiene solución verificable o criterio de respuesta abierta.
- Todo dato factual incluye fuente primaria/institucional.
- Mapas y recorridos se verifican antes de ilustrarse.
- Espacio real para responder, marcar, unir o dibujar.
- El producto no se confunde con un libro de colorear ni con fichas escolares repetitivas.
- No se usan diseños protegidos del Seguici como ilustración sin revisar derechos.

### 10. Cartografía de D13 y D14

Se ha localizado y consultado el plano turístico oficial de Reus Turisme (PDF: https://www.reusturisme.cat/sites/default/files/descarregues/PT2022%20v5.pdf). Incluye:
- Ruta del Modernisme, con marcadores numerados; Casa Navàs aparece como punto 1, Casa Gasull como 14 y Casa Rull como 15.
- Puntos de interés con Plaça Mercadal y Prioral de Sant Pere.
- Mercat Central aparece en la leyenda de mercados.

Esto permite construir mapas esquemáticos propios para D13 y D14. Antes de la ilustración, el diseñador debe contrastar las posiciones relativas y el recorrido con el plano oficial y las fichas municipales actuales. El PDF es una fuente de datos geográficos, no una plantilla que se pueda calcar. No se incorporarán escala, distancias ni tiempos de recorrido si no se validan expresamente.

### 11. Solución de respuestas abiertas

D16 no tiene respuesta única. La guía adulta debe aceptar cualquier lugar de Reus que el niño identifique o describa. Se evalúa que pueda comunicar qué le ha llamado la atención, no que recuerde una fecha o nombre concreto.
