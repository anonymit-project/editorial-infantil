# Editorial infantil – Reus

Proyecto de creación y publicación de una colección de libros
infantiles sobre Reus mediante Amazon Kindle Direct Publishing.

## Productos

1. Reus per pintar – petits (3–5 años).
2. Reus per pintar – grans (6–8 años).
3. Descobreix Reus! (5–8 años).

Idioma principal: catalán.

## Objetivo

Crear tres productos editoriales originales, de calidad comercial,
con una inversión inicial reducida y sin necesidad de mantener
inventario.

## Organización del proyecto

- PROJECT_CONTEXT.md: contexto general y criterios.
- DECISIONS.md: decisiones consolidadas.
- ROADMAP.md: planificación y estado.
- research/: investigación y derechos.
- editorial/: identidad visual y criterios gráficos.
- books/: desarrollo de cada libro.
- production/: preparación y publicación en KDP.
- commercial/: estrategia comercial y colaboraciones.

## Fuente de verdad

Este repositorio es la referencia principal del proyecto.
Las decisiones y contenidos definitivos deben quedar documentados aquí.
